# Syntax Wear

E-commerce de roupas desenvolvido com **React, TypeScript, Vite e Tailwind CSS**, com foco em uma interface moderna, responsiva e intuitiva.

**[Acessar o projeto](https://ec-syntaxwear-app.vercel.app/)**

## Sobre o projeto

O **Syntax Wear** é uma aplicação web de e-commerce desenvolvida para praticar e demonstrar conceitos modernos de desenvolvimento front-end.

O projeto apresenta uma experiência de navegação voltada para uma loja de roupas, permitindo visualizar produtos e interagir com a interface de forma responsiva em diferentes tamanhos de tela.

## Tecnologias utilizadas

* **React** — Construção da interface utilizando componentes reutilizáveis.
* **TypeScript** — Tipagem estática para maior segurança e organização do código.
* **Vite** — Ferramenta utilizada para criação, desenvolvimento e build da aplicação.
* **Tailwind CSS** — Estilização da interface utilizando classes utilitárias.
* **Vercel** — Hospedagem e deploy da aplicação.

## Funcionalidades

* Interface de e-commerce
* Exibição de produtos
* Navegação pela loja
* Layout responsivo
* Componentização com React
* Estilização com Tailwind CSS
* Desenvolvimento e build utilizando Vite
* Deploy realizado na Vercel

## Instalação

### Pré-requisitos

Antes de começar, certifique-se de ter instalado:

* [Node.js](https://nodejs.org/)
* npm ou outro gerenciador de pacotes

### Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

Entre na pasta do projeto:

```bash
cd syntax-wear
```

### Instale as dependências

```bash
npm install
```

### Execute o projeto

```bash
npm run dev
```

Após iniciar o servidor, acesse o endereço disponibilizado pelo Vite, normalmente:

```text
http://localhost:5173
```

## Build

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar a build localmente:

```bash
npm run preview
```
